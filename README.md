# agents-md

Shared AGENTS.md conventions for all [roebi](https://github.com/roebi) repositories.

## What is AGENTS.md?

A cross-agent standard for giving AI coding agents project-specific context.
Spec: https://agents.md | Steward: AAIF / Linux Foundation

## How it works

This repo contains the single source of truth for shared rules.
Each project repo has its own minimal AGENTS.md that covers:

- Project overview
- Build and test commands
- Link back to this file

## Raw URL for agents

```
https://raw.githubusercontent.com/roebi/agents-md/main/AGENTS.md
```

## Symlink for Claude Code

```bash
ln -s AGENTS.md CLAUDE.md
```
